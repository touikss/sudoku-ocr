# SudokuSolver
Semestre 3 project.

## Compilation:
    Run "make" to compile the whole project.
    It will create a "main" executable from which you can run all that you want.

## Before you start:
    You have to create an 'output' and a 'tmp' directory (which are not avaliable on the git because they are empty)

## Usage:
    Usage: ./main 

## Interface:
    Load your sudoku grid and enjoy!

## Remove:
    "make clean" will remove executable and .o files.
